# Repo Knowledge Studio design

Purpose: make an unfamiliar codebase feel like a navigable technical library. The user enters through a repository collection, reads practical handbook pages or ordered teaching chapters, and can inspect source evidence without losing their place.

## Approved palette

- Paper: `#f3f6fb`, cool studio-white.
- Ink: `#24354f`, slate-blue.
- Muted: `#5d6f89`, secondary reading information.
- Accent: `#9b542f`, copper for selected states and focal relationships.
- Surface: `#ffffff`.
- Rule: `#cbd5e4`.

Serif display headings set a reading register. System sans-serif supports controls and body text, while monospace is reserved for source paths, revisions and code. Use system fallbacks and local assets so generated guides remain usable offline.

## Shared visual language

Custom SVG diagrams use the same palette, generous node padding, few focal elements, explicit edge semantics, accessible descriptions, and bounded complexity. Split dense architecture views rather than shrinking text. Video compositions reuse these concepts and evidence IDs, with progressive scene timing and readable captions. No Mermaid.
