# Repo Knowledge Studio diagram profile
User-approved custom palette: warm white #faf9f6; slate blue ink #263b50; secondary #526477; copper accent #98532f; copper tint #f3e6dc; rule #b9c4cd.
Follow diagram-design philosophy: source-grounded nodes, sparse relationships, at most eight concepts per figure, one focal node, orthogonal connectors, accessible SVG title/description, escaped labels. Do not generate Mermaid.
Use system sans and monospace in offline diagrams; these are explicit offline substitutes for Geist and Geist Mono. Render browser wrappers with local horizontal scrolling at native SVG width. Static SVG remains complete without scripts.
